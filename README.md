# DevOps Academy

A tiny, zero-build static website used as the demo project for the **Git & GitHub** session. It is a simple course landing page: a header, a nav, a list of courses, a dark-mode toggle, and a footer. Open `index.html` in any browser — there is no build step, no npm, nothing to install. We use it purely as realistic content to practice real Git operations on.

Git staging and commit practice.
